# MotoWatch OMO-X

Wear OS smartwatch application for OMOWAY OMO-X.

## Target Device
- Samsung Galaxy Watch 6
- Wear OS

## Planned Features
- Motorcycle status
- Battery monitoring
- Estimated riding range
- Lock and unlock
- Start and stop control
- Vehicle connectivity

## Development Status
Version 0.1 - UI Prototype

This project is currently a simulation.
It does not control a real motorcycle.
